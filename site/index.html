DastYab (دستیاب)

A complete Cloudflare Workers VLESS VPN console. Deploy a worker, scan for clean IPs, and export client configs for v2rayN, sing-box, and Clash — all from one fast, safe, static Rust binary.

Why the Rust version?

This is the Rust rewrite of the classic Python console. It keeps all the same power and adds real engineering advantages.

🚀

Single binary

No Python, no pip, no Node. A static executable that runs anywhere.

🛡️

Memory-safe

Rust guarantees no null pointers, buffer overflows, or data races.

⚡

Fast

Clean-IP scanning and analytics feel instant, even on modest hardware.

🌍

Cross-platform

Linux, macOS, Windows, and ARM from one codebase.

📦

Type-safe APIs

Every Cloudflare object is a serde model — no loose JSON poking.

📖

Fully documented

Architecture maps, module guides, and a design reference included.

Expert-grade tooling

  • Deploy workers with anti-bot stealth pacing and per-deploy byte humanization.
  • Scan clean IPs via SenPaiScanner, verified with real health probes.
  • Export configs for v2rayN, sing-box, and Clash (YAML/JSON).
  • Manage DNS & zones — list, create, and delete records.
  • Manage worker routes — map patterns to scripts.
  • Usage analytics — per-worker request and traffic summaries.
  • Security audit — checks token permissions and flags leaks.
  • Backup & restore — portable profile bundles.
  • Endpoint diagnostics — latency & throughput ranking.
  • Self-update — check & fetch newer releases from GitHub.
  • Deploy presets — standard / gaming / max-compat.
  • Three frontends — CLI, TUI, and desktop GUI.

Quick start

Build the release binary

cargo build --release --workspace

Add a Cloudflare API token

dastyab token add cf-main <YOUR_CF_API_TOKEN>

Stored at 0600 in ~/.dastyab/.

Verify & deploy a worker

dastyab verify
dastyab deploy --preset standard

Find a clean IP

dastyab scan

Export client configs

dastyab export clash    --output clash.yaml
dastyab export singbox  --output config.json
dastyab export v2rayn  --output xray.json

Prefer a dashboard? Run dastyab-tui for a terminal UI or dastyab-gui for the desktop app.

Storage, built for safety

All state lives under ~/.dastyab/. Every write is atomic (tempfile + fsync + rename), so a crash or kill can never corrupt your tokens or configs. 

~/.dastyab/
├── profiles/
│   └── default/
│       ├── profile.json    # metadata
│       ├── token.json      # API tokens (mode 0600)
│       ├── accounts.json   # CF accounts
│       ├── history.json    # generated vless configs
│       ├── cleanips.json   # scanned clean IPs
│       └── config.json     # settings
├── backups/                # exported profile bundles
└── legacy/                 # migrated pre-0.1 files
